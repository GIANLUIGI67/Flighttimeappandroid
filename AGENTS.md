# Agent instructions

## Skills: check before every task

Before starting any non-trivial task, (1) check skills already available in this repo and environment; (2) if none fits, search with the pinned CLI only: `npx -y skills@1.8.1 find '<keywords>'` (skills.sh) and use the find-skills skill — always single-quote keywords; never paste untrusted text into an unquoted shell command; (3) search only with generic keywords (no confidential or personal details); if the task cannot be summarized safely for an external search, skip the search and continue the task; (4) if the search fails, continue the task without it; (5) vet any hit (prefer 1K+ installs, reputable owner, read SKILL.md and scripts; reject anything asking for secrets or running opaque downloads); (6) apply a suitable skill; installing a *new* skill requires Gianluigi's explicit ok first (then `npx -y skills@1.8.1 add <owner/repo@skill> -y` if it will be reused); (7) if nothing fits, proceed normally. Installing a skill never authorizes deploys, publishing, spending or sending messages.
